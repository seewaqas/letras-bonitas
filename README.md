# Letras Bonitas

Spanish fancy-text generator. Type once, copy a Unicode style, paste it into Instagram, WhatsApp, TikTok, or a Free Fire nickname.

```bash
npm install
npm test
npm run dev
```

Set `SITE_URL` to the real domain before a production build if you want canonical URLs and a sitemap:

```bash
SITE_URL=https://example.com npm run build
```

Free Fire nicknames are limited to 12 characters. That page is `/letras-para-free-fire/`.
